## 编码

对着当前项目写功能、改实现、跑检查。

- 先读文件，再按内容创建、替换或分块修改；一次可预览多个文件再提交。
- 回复下方汇总本轮增删，打开 diff，撤销本轮工作区里的文本修改。
- 本机命令用于构建、测试、调试和装依赖；开发服务可以驻留，停止本轮对话不会把它关掉。
- 内置 Python 在独立环境里跑脚本和管依赖，不改系统解释器。
- 保存前记下诊断，改完再核对。写入完成不等于测试通过。

---

## 代码审计

审查必须落到位置和证据，而不是一段笼统结论。

- 在工作区里检索、分页读代码，并查看语言服务诊断。
- 沿定义和调用链看实现，重命名前可以预览影响范围。
- 把编辑器里选中的代码附进当前会话，审查用的是提交当时的快照。
- 漏洞候选要写清影响和证据；删掉一条笔记要留下原因。
- 审计里的假设，用远程命令或浏览器再验证；确认要改的，回到编码流程，本轮 diff 可以复查。

单个模块用协助对话。要覆盖一组路由、清掉高危项这类带验收的任务，用目标模式。

## 渗透测试

把授权范围内的 Web 和主机测试收成可追踪的过程。

<p align="center">
  <img src="docs/images/assist.png" alt="协助模式：远程探测与工具审批">
</p>

- **远程 Linux 优先。** 侦察、枚举、扫描和漏洞验证走已配置的 SSH。命名会话保留目录和环境；长命令可中断或放到后台。SSH 主机是执行环境，题目或资产的地址以任务证据为准。
- **攻击面台账。** 从种子域展开子域、证书、别名和跳转。关联出来的主机默认在范围内；覆盖没做完，不能当成安全阶段已验收。
- **页面与公开信息。** 内置浏览器看页面和 DOM，公开检索补背景。需要在目标环境落地时，再用远程命令。
- **无回显场景。** 技能可接 DNSLog，覆盖盲 SSRF、XXE、命令注入和 SQL 注入。
- **笔记。** 区分过程记录、资产和漏洞候选（目标、向量、严重级别、证据、利用链提示）。候选可以提升到探索图，提升之前仍是待确认项。
- **审批。** 默认每次工具调用选择允许一次或拒绝。

CTF 和明确授权的赛题按同一套执行：附件、本地环境和指定靶机视为题目范围；枚举、验证和取 flag 优先在远程 Linux 上完成，附件用 SFTP 送上去。本机用来看附件、写脚本和跑加解密草稿。SSH 或工具不可用时说明限制，并改走允许的替代路径。

独立的渗透或审计不必走交付台账。交付闭环用于「开发 → 审计 → 安全 → 部署 → 运维」的阶段验收。

## 目标模式与探索图

长任务先写目标和验收，再并行推进。探索图把事实和意图连成一张可以搜索、可以顺着证据走的图。

<p align="center">
  <img src="docs/images/explore.png" alt="探索图：事实、意图、待补证与漏洞笔记">
</p>

- **概览**：目标、验收进度、思考和调度。
- **探索图**：按事实、意图、关注点或节点搜索；追溯上游证据，或追踪下游分支。执行中的意图指向待产出的节点，完成后指向产出的事实。
- **任务**：Worker 分头读代码、写脚本、在远端验证，记录仍归同一会话。
- **笔记**：资产、漏洞候选和过程记录，可提升到图上。

运行中可以切到别的会话，后台继续写回原来的任务。切走不会停执行，也不会误批另一个会话的工具。

## 运维发布

新项目可以按阶段验收，再进入发布。阶段顺序是：开发、审计、安全、部署、运维。

- 安全和部署必须引用真实执行证据，不能用进度说明代替。
- 安全阶段要求授权范围，并且攻击面覆盖完成。
- 部署阶段记录已发布的访问地址，以及从哪一侧做的验证。
- 运维阶段写明回滚办法。
- 未关闭的严重或高危问题会挡住发布。证据过期后要重跑检查，不能沿用失效结果。

## 开始使用

Windows x64 安装后启动 `UBOVM.exe`。用户数据在 `~/.ubovm/desktop/`。

从源码启动需要 **Node.js 24**（低于 25）。Windows 用 PowerShell；macOS / Linux 需要 PowerShell 7（`pwsh`）。

```sh
npm install
node build/build.mjs setup
node build/build.mjs start
```

建议先配置模型，再配置 SSH（渗透和 CTF 的远程执行环境），然后按任务打开浏览器、搜索、DNSLog、MCP 和 Skills。

界面开发用 `node build/build.mjs dev`。其余动作见 `node build/build.mjs help`。

工作区文件受目录边界约束。API Key 不进入对话页面。题目文件和工具输出都是待核对的证据，不能据此扩大授权范围。
