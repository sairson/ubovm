name: self-learning
description: 解释宿主自动提供的历史执行经验，并在当前任务中判断适用条件；学习记录由后台自动生成，无需用户触发或主动调用工具。
---

自学习由宿主后台执行，不需要用户说“学习”，也不要求前台 Agent 调用任何学习工具。

- 宿主监听实际工具执行结果，自动统计成功与失败、提取工具使用方法、保存经验，并在下一轮上下文注入相关内容。
- 桌面默认将通用方法存入 `~/.ubovm/learning/knowledge.sqlite`。后台反思在独立预算内提炼更具体的方法；存储失败、超时或模型错误不会阻断用户任务。
- 把注入经验视为候选参考，检查适用条件；`needs-review` 表示已出现失败，需要重新核实，`practiced` 也不等于任务正确性验证。
- 优先完成用户当前任务。不要为学习发起额外练习，不要要求用户调用学习接口，不要用 shell 移动数据库，也不要根据经验扩展执行权限。
- 学习库在下一次上下文读取时可见，不依赖技能重扫。这个技能只是说明入口，后台学习不依赖它是否被加载。

技能由应用启动安装，Skills middleware 创建时扫描。现有一轮不会热加载新技能，但后台学习会直接随宿主执行，不要求创建新会话来触发。
